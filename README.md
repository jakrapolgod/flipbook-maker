# Flipbook Maker

แอปสร้าง ebook แบบพลิกหน้า (flipbook) จาก **รูปภาพ** หรือ **PDF** — ทำงานในเครื่องทั้งหมด
ไม่ต้องสมัครสมาชิก ไม่ต้องอัปโหลดไฟล์ขึ้นบริการใคร และไม่ต้องต่อเน็ตตอนใช้งาน

## เริ่มใช้งาน

ดับเบิลคลิก `start.cmd` (หรือสั่ง `node server.js`) แล้วเบราว์เซอร์จะเปิดที่ http://localhost:5173

## ขั้นตอน

1. **เพิ่มรูปภาพ** หรือ **นำเข้า PDF** — กดปุ่มด้านบน หรือลากไฟล์มาวางบนหน้าต่างก็ได้
   (PDF หลายไฟล์/รูปหลายรูปพร้อมกันได้ รูปจะเรียงตามชื่อไฟล์แบบธรรมชาติ)
2. **จัดหน้า** — ลากการ์ดเพื่อสลับลำดับ, หมุนหน้า, ลบหน้า, กลับลำดับทั้งเล่ม
3. **พรีวิว** — ทดลองพลิกอ่านจริงก่อน export
4. **Export** — เลือกได้ 2 แบบ (ดูหัวข้อถัดไป)

## รูปแบบไฟล์ที่ได้

| แบบ | ได้อะไร | เหมาะกับ |
| --- | --- | --- |
| **ไฟล์เดียว (.html)** | ไฟล์ HTML ไฟล์เดียว ฝังทุกหน้าไว้ข้างในเป็น data URI | ส่งทางไลน์/อีเมล, ใส่ USB, ดับเบิลคลิกเปิดได้เลย |
| **แพ็กเกจเว็บ (.zip)** | `index.html` + `assets/` + `pages/001.jpg…` | อัปโหลดขึ้นเว็บโฮสต์เพื่อ **แชร์เป็นลิงก์** |

ทั้งสองแบบเปิดได้โดยไม่ต้องต่อเน็ต ไม่ต้องใช้ PHP หรือฐานข้อมูล

## แชร์ให้คนอื่นดูออนไลน์

เลือก Export แบบ **แพ็กเกจเว็บ (.zip)** แล้วแตกไฟล์ จะได้โฟลเดอร์เว็บสถิตล้วน
อัปโหลดทั้งโฟลเดอร์ขึ้นที่ไหนก็ได้ แล้วส่งลิงก์ที่ชี้ไปยัง `index.html`

- **cPanel / โฮสต์เดิม** — อัปโหลดเข้า `public_html/ชื่อหนังสือ/` แล้วเปิด `https://โดเมน/ชื่อหนังสือ/`
- **Netlify Drop** — ลากโฟลเดอร์วางที่ app.netlify.com/drop ได้ลิงก์ทันที ฟรี
- **Cloudflare Pages / GitHub Pages / Vercel** — ใช้ได้หมด เพราะเป็นไฟล์สถิต
- **Google Drive** — เหมาะกับแบบ **ไฟล์เดียว (.html)** มากกว่า (Drive ไม่เสิร์ฟเว็บเป็นโฟลเดอร์)

## การป้องกันด้วยรหัสผ่าน

แต่ละเล่มเลือกได้ 2 แบบในช่อง **การป้องกันเล่มนี้**

| แบบ | ผลลัพธ์ |
| --- | --- |
| **ไม่เข้ารหัส** | ใครมีลิงก์หรือไฟล์ก็เปิดอ่านได้ทันที เหมาะกับเอกสารเผยแพร่ทั่วไป |
| **เข้ารหัส** | ต้องกรอกรหัสผ่านก่อนอ่าน ทุกหน้าถูกเข้ารหัสจริงตั้งแต่ตอน export |

### เข้ารหัสอย่างไร

ไม่ใช่การเอา JavaScript มาบังหน้าจอ แต่เข้ารหัสตัวไฟล์จริง

- คีย์มาจากรหัสผ่านด้วย **PBKDF2-SHA256 250,000 รอบ** พร้อม salt สุ่ม 16 ไบต์
- แต่ละหน้าเข้ารหัสด้วย **AES-256-GCM** โดยมี IV สุ่มของตัวเอง
- ชั้นข้อความที่ใช้ค้นหาก็ถูกเข้ารหัสด้วย
- ในแพ็กเกจเว็บ ไฟล์หน้าจะกลายเป็น `pages/001.bin` ซึ่งเป็นข้อมูลที่เข้ารหัสแล้ว
  โหลดไปเปิดตรง ๆ ไม่ได้ ไม่ใช่ไฟล์รูป
- ไฟล์ที่ export จะไม่มีรหัสผ่านอยู่ข้างใน และไม่มีรูปที่อ่านได้หลงเหลือ

หน้าแรกจะถูกถอดรหัสก่อนแล้วเปิดอ่านได้เลย ที่เหลือทยอยถอดในเบื้องหลัง เล่มหนาจึงยังเปิดได้เร็ว

### ข้อจำกัดที่ต้องเข้าใจ

- **ต้องเปิดผ่าน https** (หรือ localhost / ไฟล์ในเครื่อง) เพราะเบราว์เซอร์ให้ใช้ Web Crypto
  เฉพาะหน้าที่ปลอดภัย — เว็บที่เป็น http ล้วนจะถอดรหัสไม่ได้
- **ไฟล์ที่เข้ารหัสเปิดให้ทุกคนดาวน์โหลดได้** ความปลอดภัยจึงขึ้นกับความยาวของรหัสผ่าน
  รหัสสั้นถูกเดาแบบออฟไลน์ได้ ควรตั้งยาว ๆ
- **กันคนที่ได้รหัสไปแล้วไม่ได้** เขาเปิดอ่านและส่งต่อสิ่งที่ถอดแล้วได้เสมอ
- **ลืมรหัสผ่านแล้วกู้ไม่ได้** ต้อง export ใหม่
- ถ้าต้องการควบคุมเป็นรายคน (ใครเข้าได้บ้าง ถอนสิทธิ์ได้ ดูประวัติการเข้าถึงได้)
  ต้องใช้ระบบยืนยันตัวตนฝั่งเซิร์ฟเวอร์อย่าง Cloudflare Access ซึ่งอยู่นอกขอบเขตของแอปนี้

สารบัญภาพย่อ · ค้นหาข้อความ (เฉพาะหนังสือที่นำเข้าจาก PDF ที่มีชั้นข้อความ) · ซูมและเลื่อนดู ·
**แว่นขยาย** · เล่นอัตโนมัติ · เสียงพลิกหน้า (สังเคราะห์ในตัว ไม่ต้องมีไฟล์เสียง) · เต็มจอ ·
คีย์ลัด `←` `→` `Home` `End` `F` `M`

### แว่นขยาย

กดปุ่ม 🔍 บนแถบเครื่องมือ (หรือกด `M`) แล้วเลื่อนเมาส์ไปบนหน้าหนังสือ จะมีวงแว่นตามไปขยายจุดนั้น

- หมุนล้อเมาส์ขณะเปิดแว่น เพื่อปรับกำลังขยาย 1.5–5 เท่า (ค่าเริ่มต้น 2.5 เท่า)
- บนมือถือ แตะค้างแล้วลากนิ้วไปบนหน้าหนังสือ
- แว่นจะซ่อนเองเมื่อออกนอกขอบหนังสือ หรืออยู่เหนือครึ่งที่ว่าง (ตอนปกหน้า/ปกหลัง)
- ขณะเปิดแว่น การลากพลิกหน้าจะถูกปิดไว้ ใช้ปุ่มลูกศรหรือแถบเลื่อนหน้าแทน

## โครงสร้างโปรเจกต์

```
index.html          หน้าตาแอปตัวแก้ไข
css/app.css         สไตล์ของตัวแก้ไข
css/flipbook.css    สไตล์ของตัวอ่าน (ถูกฝังลงไฟล์ที่ export ด้วย)
js/flipbook.js      เอนจินพลิกหน้า ไม่พึ่งไลบรารีใด ๆ (ฝังลงไฟล์ที่ export ด้วย)
js/app.js           ตรรกะตัวแก้ไข: นำเข้า, จัดหน้า, เรนเดอร์, พรีวิว
js/export.js        ตัวประกอบไฟล์ .html และ .zip
js/protect.js       เข้ารหัส/ถอดรหัสเล่มที่ตั้งรหัสผ่าน (ฝังลงไฟล์ที่ export ด้วย)
vendor/             pdf.js (อ่าน PDF) และ JSZip (ทำ .zip)
tools/              สคริปต์ช่วย เช่น แปลง .html ไฟล์เดียวเป็นแพ็กเกจเว็บ
server.js           เว็บเซิร์ฟเวอร์เล็ก ๆ ไม่มี dependency
```

## หมายเหตุทางเทคนิค

- หน้าทุกหน้าถูกเก็บเป็น **ต้นฉบับ** ไว้ในหน่วยความจำ แล้วเรนเดอร์ใหม่ตอน export
  ปรับความกว้าง/คุณภาพ JPEG ทีหลังได้โดยไม่ต้องนำเข้าใหม่
- PDF ถูกเรนเดอร์ด้วย `intent: 'print'` เพื่อให้ pdf.js ไม่ผูกกับ `requestAnimationFrame`
  งานนำเข้าไฟล์ใหญ่จึงทำงานต่อได้แม้ผู้ใช้สลับไปแท็บอื่น
- ข้อความจาก PDF จะถูกดึงมาเก็บไว้ในไฟล์ที่ export เพื่อให้ค้นหาได้
  PDF ที่เป็นภาพสแกนล้วนจะไม่มีชั้นข้อความ ตัวอ่านจะแจ้งให้ทราบเมื่อค้นหา
- ขนาดไฟล์โดยประมาณ: 1400 พิกเซล / คุณภาพ 82% ได้ราว 35–40 KB ต่อหน้า
